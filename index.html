設定教學 / 操作手冊

換新電腦或第一次使用時的設定步驟。設定值只存在每台裝置，需各自設定一次（資料則透過 Google Sheet 同步）。

重點觀念

  • 委託「資料」存在 Google Sheet，任何電腦都讀同一份。
  • 但「設定」（Apps Script URL、金鑰）存在各台電腦本機，每台新電腦要各自貼一次。
  • 辨識優先順序：Google Vision 座標式 → Google Drive OCR → OCR.space → 離線。設好 Apps Script URL 後即用 Vision（最準）。

A. 換新電腦最快上手（資料已建好過）

  1. 開啟本系統 → 右上「⚙ 設定」。
  2. 把既有的 Apps Script 網頁應用程式 URL（結尾 /exec）貼到欄位，按「儲存設定」。
  3. 按「⬇ 從 Sheet 載入」把雲端資料抓下來。
  4. 完成。辨識會自動走 Google Vision，不需再下載任何離線模型。

若辨識一直顯示「下載中文模型中…」卡住，就是這台沒設定 URL、退到離線辨識且被網路擋。請依上面步驟填入 URL。

B. 第一次建置（從零開始，只需做一次）

B-1 建立試算表與後端

  1. Google 雲端硬碟新增一個 Google 試算表。
  2. 試算表選單「擴充功能 → Apps Script」，把編輯器內容清空，貼上提供的 GoogleAppsScript_程式碼.gs，存檔。
  3. 編輯器左側「服務」按「＋」，新增 Drive API（離線備援 OCR 用）。

B-2 部署成網頁應用程式

  1. 右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」。
  2. 執行身分：我（你的帳號）；誰可以存取：有 Workspace 選「網域內所有人」，否則選「任何人」。
  3. 部署、依畫面授權（出現未經驗證警告時點「進階 → 繼續」）。
  4. 複製產生的 URL（結尾 /exec），貼進系統「⚙ 設定」。

B-3 Google Vision 座標式辨識（最準，選配·需金鑰）

表格式排版的委託單用這個最準。金鑰現在可直接填在「⚙ 設定」，不需要改程式碼。

  1. 到 Google Cloud Console（console.cloud.google.com），登入後在上方選一個專案；沒有專案就按「建立專案」新增一個。
  2. 左側選單進入「API 和服務 → 程式庫」（APIs & Services → Library）。
  3. 在搜尋框輸入「Vision」，點選結果中的「Cloud Vision API」（可能顯示為 Cloud Vision API / Vision AI）。要選的就是這個 Cloud Vision API，不是 Vision 其他產品、也不是 AutoML/Document AI。
  4. 進入後按「啟用」（Enable）。第一次啟用會要求綁定帳單帳戶（需綁信用卡）；Vision 每月前 1,000 次辨識免費，一般用量多在免費額度內。
  5. 啟用後到「API 和服務 → 憑證」（Credentials）→「建立憑證」→「API 金鑰」，會產生一組 AIzaSy… 開頭的金鑰，複製起來。
  6. （強烈建議）點該金鑰旁的編輯 → 「API 限制」選「限制金鑰」→ 只勾選「Cloud Vision API」。這樣即使金鑰外洩也只能用在 Vision。
  7. 回到本系統「⚙ 設定」→「Cloud Vision API 金鑰」欄位貼上金鑰 → 按「儲存設定」。填了金鑰＋Apps Script URL 就會啟用座標式辨識。不需要改程式碼、也不需要重新部署。

若想全公司共用同一把金鑰、不必每台各自輸入，也可改由後端統一設定：把金鑰貼在 .gs 檔第一段的 var VISION_API_KEY = '';（前端未填時會用這把），存檔後重新部署（部署 → 管理部署作業 → 編輯 → 版本：新版本）。

安全提醒：API 金鑰等於你 Google Cloud 帳戶的一把鑰匙，切勿貼到公開場合或聊天訊息。若不慎外洩，到「憑證」把該金鑰刪除或重新產生，並務必加上上面第 6 步的「限制」。

B-4 OCR.space（選用備援）

  1. 到 ocr.space 免費註冊取得金鑰，貼進「⚙ 設定」的 OCR.space 欄位。

C. 疑難排解

  • UrlFetchApp 權限 / external_request 錯誤：Apps Script 編輯器函式選單選 authorize → 執行 → 允許（含「連線至外部服務」）；再「管理部署作業 → 編輯 → 新版本」重新部署。
  • requires billing to be enabled：到 Cloud Console 帳單，把指定的專案連結帳單帳戶，等幾分鐘再試。
  • 上傳/載入失敗、CORS：多半是部署「誰可以存取」沒設成任何人／網域內所有人，或 URL 沒到 /exec。重新部署、重貼 URL。
  • 改了 .gs 沒生效：要「管理部署作業 → 編輯 → 版本選新版本」才會套用。
